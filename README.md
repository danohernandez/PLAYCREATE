# PLAYCREATE

Playbook de básquetbol para computadora y tablet. Abre `index.html` en un navegador o publica la raíz de la rama `main` con GitHub Pages.

## Funciones

- Cancha completa o media cancha, jugadores y defensores X1, X2…
- Trazos de movimiento, pase, bote y bloqueo.
- Carpetas con colores, secuencias independientes, temas claro y oscuro.
- Selección de jugadas o carpetas para imprimir y guardar como PDF.
- Guardado en el navegador y respaldo/importación JSON.

Los datos permanecen en el dispositivo y navegador; no se sincronizan con GitHub ni entre dispositivos. Descarga respaldos para conservarlos.

## Publicación

En Settings → Pages, selecciona Deploy from a branch, rama main y carpeta / (root), y guarda. La dirección prevista es https://danohernandez.github.io/PLAYCREATE/ una vez que GitHub termine el despliegue.

## Desarrollo

Esta primera versión es un prototipo HTML autónomo sin dependencias externas. Los cambios de código se guardan mediante commits en este repositorio. Requiere pruebas visuales y de interacción en dispositivos reales.
